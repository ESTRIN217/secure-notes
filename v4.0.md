# Plan de Lanzamiento: Secure Notes v4.0.0

---

## 1. Características (Features)

Nuevas funcionalidades e integraciones que aportan valor directo al usuario final.

### Autenticación y Sincronización
* **Autenticación con Google:** Apartado dedicado para el inicio de sesión único (SSO) del usuario.
* **Sincronización con Google Drive:** Integración real y nativa para la gestión de copias de seguridad en la nube y persistencia de datos.

### Editor y Herramientas de Texto
* **Inteligencia Artificial Integrada:** Capacidades fluidas para redactar, resumir y reescribir contenido directamente en el editor mientras se escribe.
* **Soporte Avanzado para Markdown:** Renderizado y aplicación de estilos visuales rápidos (negritas, listas anidadas, creación de tablas) de forma ligera.
* **Herramientas de Código:** Visor con resaltado de sintaxis y enumeración de líneas para edición rápida de scripts o archivos de configuración.
* **Gestor de Archivos y Sistema:**
  * Apertura de archivos externos e internos (`.txt`, `.md`, `.html`, `.json`, `.pdf`).
  * Integración con el sistema operativo para aparecer en el diálogo de "Compartir texto" del dispositivo.

### Interfaz de Usuario y UX
* **Pestañas Múltiples:** Organización de varios documentos abiertos de forma simultánea dentro de una sola ventana para evitar desorden.
* **Modo Flotante (Burbuja):** Acceso rápido a la aplicación en superposición desde cualquier pantalla del sistema.
* **Widgets de Pantalla de Inicio:** Accesos directos y vistas rápidas de notas en el launcher del dispositivo.

## 2. Mejoras (Improvements)

Optimización y evolución de sistemas e interfaces existentes.

### Rendimiento
* **Editor optimizado para archivos largos:** El parser `RichTextParser.parseWithMapping` se ejecuta en cada pulsación de tecla.
  * **(COMPLETADO)** Las 3 llamadas redundantes en `remember(contentValue)` para toolbar state se fusionaron en 1 con debounce de 80ms mediante `snapshotFlow` + `LaunchedEffect`.
  * **(COMPLETADO)** `VisualTransformation` ahora cachea el resultado de `parseWithMapping` por texto, evitando re-parses duplicados en el mismo frame.
* **Toolbar y teclado sin espacio muerto:** Corregir el padding excesivo entre la barra de herramientas flotante y el teclado virtual al editar etiquetas.
  * **(COMPLETADO)** Se eliminaron 3 llamadas redundantes a `navigationBarsPadding()` dentro de `ModalBottomSheet` (Material3 ya maneja insets).

### UI/UX Adaptativa y Diseño
* **Diseño Responsivo:** Implementación de vistas dedicadas para móvil y tablet.
  * `MainListScreen` actualmente usa una sola columna fija. Adaptar a `WindowWidthSizeClass` para landscape y tablets.
  * **(COMPLETADO)** Reemplazado `isLargeScreen = screenWidthDp >= 600` por `WindowWidthSizeClass` (Compact/Medium/Expanded) con umbrales M3 estándar (600/840dp).
  * **(COMPLETADO)** Grid adaptativo: 2 columnas en Compact/Medium, 3 en Expanded.
  * **(COMPLETADO)** NavigationRail: inicia expandido solo en Expanded, colapsado en Medium, Drawer en Compact.

* **Consistencia Estética:** Adhesión estricta a las guidelines de **Material Design 3 Expressive (Outlined)** en toda la aplicación — los parámetros `BorderStroke` están duplicados en `DrawingCanvasScreen.kt:184-193` y `464-471`. Extraer a constantes compartidas.
  * **(COMPLETADO)** Extraído a `val canvasCardBorderStroke = BorderStroke(2.dp, MaterialTheme.colorScheme.primary)` en `DrawingCanvasScreen.kt:181`.

### Seguridad y Resiliencia
* **Robustez del Sistema:** Mecanismo de guardado automático para eliminar el riesgo de pérdida de información ante cierres inesperados. Actualmente `saveNoteAndGetId` (`NotesViewModel.kt:341-390`) es `suspend` pero no garantiza `Dispatchers.IO` para cifrado y JSON.
  * **(COMPLETADO)** Envuelto `saveNoteAndGetId` en `withContext(Dispatchers.IO)` para evitar bloqueo del Main Thread durante PBKDF2 (10k iteraciones).
  * **(COMPLETADO)** Agregado try/catch con `Log.e()` para errores de cifrado/inserción.
  * **(COMPLETADO)** Auto-save con debounce de 2s vía `snapshotFlow` + `collectLatest` en `NoteEditorScreen` para cambios de contenido, título y etiquetas.
* **Capa de Privacidad:** Reemplazar tokens simulados (`"ya29.simulated_access_token"` en `BackupViewModel.kt:67` y `MainActivity.kt:2329`) con autenticación OAuth real (Credential Manager / GoogleSignIn).
  * **(COMPLETADO)** Agregada dependencia `play-services-auth:21.2.0`.
  * **(COMPLETADO)** Reemplazado input manual de token + token simulado con botón "Sign in with Google" vía `GoogleSignInClient`.
  * **(COMPLETADO)** Obtención de access token real con scope `drive.file` mediante `GoogleAuthUtil.getToken()` en `Dispatchers.IO`.
  * **(COMPLETADO)** `BackupRestoreScreen` ahora navega a `CloudSyncScreen` para el flujo de autenticación.
  * **(COMPLETADO)** Eliminadas strings obsoletas: `token_label`, `token_placeholder`, `token_info_text`, `toast_simulation_token_seeded`.

### Internacionalización (strings.xml)

**Reglas Clean Code a aplicar en todo el código base:**
- Funciones ≤ 20 líneas y una sola responsabilidad.
- Nombres con verbos (`saveNote`, `encryptContent`, `toggleDarkMode`).
- Un solo nivel de abstracción por función.
- Guard clauses en vez de `if/else` anidados.
- Sin cadenas nullables de más de 2 niveles.
- Los comentarios explican **por qué** (decisión de diseño, edge case), nunca **qué**.

## 5. Criterios de Aceptación

- [ ] **Cobertura de tests:** No disminuye respecto a v3.x.
- [ ] **Sin regresiones:** Todos los tests unitarios e instrumentados pasan (`./gradlew test && ./gradlew connectedCheck`).
- [ ] **Sin `object` estáticos para servicios:** Encryption, Sync, Export, RichTextParser son inyectables.
- [ ] **Sin `catch` vacíos ni `e.printStackTrace()`:** Todo error se loguea con `Log.e()` o se propaga como tipo sellado.
- [ ] **Funciones ≤ 20 líneas:** Excepciones documentadas y justificadas.
- [x] **Sin modelos duplicados:** `ListItem` eliminado.
- [x] **Sin repositorio innecesario:** `NoteRepository` eliminado.
- [ ] **Sin código muerto:** Comentarios de template eliminados; funciones no usadas eliminadas.
- [ ] **Sin tokens simulados:** OAuth real con Google Sign-In / Credential Manager.
- [ ] **UI responsiva:** Layout adaptativo para tablets y landscape.
