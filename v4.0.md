**Reglas Clean Code a aplicar en todo el código base:**
- Funciones ≤ 20 líneas y una sola responsabilidad.
- Nombres con verbos (`saveNote`, `encryptContent`, `toggleDarkMode`).
- Un solo nivel de abstracción por función.
- Guard clauses en vez de `if/else` anidados.
- Sin cadenas nullables de más de 2 niveles.
- Los comentarios explican **por qué** (decisión de diseño, edge case), nunca **qué**.

## 5. Criterios de Aceptación

- [ ] **Cobertura de tests:** No disminuye respecto a v3.x.
- [ ] **Sin regresiones:** Todos los tests unitarios e instrumentados pasan (`./gradlew test && ./gradlew connectedCheck`).
- [x] **Sin `object` estáticos para servicios:** Encryption, Sync, Export, RichTextParser son inyectables.
- [x] **Sin `catch` vacíos ni `e.printStackTrace()`:** Todo error se loguea con `Log.e()` o se propaga como tipo sellado.
- [ ] **Funciones ≤ 20 líneas:** Excepciones documentadas y justificadas.
- [x] **Sin modelos duplicados:** `ListItem` eliminado.
- [x] **Sin repositorio innecesario:** `NoteRepository` eliminado.
- [x] **Sin código muerto:** Comentarios de template eliminados; funciones no usadas eliminadas.
- [x] **Sin tokens simulados:** OAuth real con Google Sign-In.
- [x] **Sin tokens en texto plano:** Almacenados en `EncryptedSharedPreferences`.
- [x] **Token refresh automático:** No requiere re-autenticación al expirar.
- [x] **Sync background:** WorkManager con periodicidad 6h + constraints de red.
- [x] **Resolución de conflictos:** Merge por `lastModified` en restauración.
- [x] **Barra de progreso:** Etapas visibles durante sync (encrypting, searching, uploading/downloading, restoring).
- [x] **Scope Drive correcto:** `drive.appdata` para `appDataFolder`.
- [x] **Plugin google-services:** Configurado con Firebase Analytics.
- [x] **Sin código muerto en auth:** Imports y reglas ProGuard obsoletas eliminados.
- [x] **UI responsiva:** Layout adaptativo para tablets y landscape.
- [x] **AI Local integrado:** Editor con asistente IA vía Ollama o modelo on-device.
- [x] **Toggle on/off de IA:** En settings, desactivable por el usuario.
